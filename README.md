# PCMDM2: predicting metabolomic profiles from microbial abundance profiles using a phylogeny-informed deep learning framework

The functional connections between the microbiome and metabolome provide a basis for predicting metabolomic profiles from low-cost, high-throughput microbiome data. Although existing methods have advanced metabolomic profile prediction, their incorporation of evolutionary relationships among microbes remains limited. To address this limitation, we developed PCMDM2, a phylogeny-informed dual-branch deep learning framework for predicting metabolomic profiles from microbiome data.

## Framework of PCMDM2

The PCMDM2 framework comprises three main steps:

(i) **Construction of phylogeny features:** Microbial abundance profile are reordered through postorder traversal of an NCBI taxonomy-based phylogenetic tree . An additional representation of distantly related taxa is generated through interval-based sampling of the reordered abundance profile. The two  profile are concatenated to form phylogeny features that capture both close and distant phylogenetic relationships.

(ii) **CNN–MLP fusion learning:** The phylogeny feature branch uses a one-dimensional convolutional neural network (1D-CNN) to learn from the constructed phylogeny features, while the parallel abundance branch uses a multilayer perceptron (MLP) to process the original CLR-transformed microbial abundance profiles. The learned representations are then fused for downstream prediction.

(iii) **Metabolite abundance prediction:** The fused representation is used to predict the abundance of each target metabolite.

## Usage

### 1. Prepare input data

PCMDM2 requires three input tables: genus-level microbial abundances, metabolite abundances, and sample metadata.

#### 1.1 Microbial abundance table

- Row identifiers must contain the full taxonomic lineage, as genus names are extracted from the `g__` field (e.g., `d__Bacteria;p__Firmicutes_A;c__Clostridia;o__Peptostreptococcales;f__Acidaminobacteraceae;g__Fusibacter_A`).
- Column headers are sample IDs.

Example format (illustrative values):

| Feature                                                      | PRISM.7122 | PRISM.7147 | ...  |
| ------------------------------------------------------------ | ---------- | ---------- | ---- |
| d__Bacteria;p_Firmicutes_A;c_Clostridia;o_Peptostreptococcales;f_Acidaminobacteraceae;g_Fusibacter_A | 1.30E-06   | 4.51E-07   | ...  |
| d__Bacteria;p_Firmicutes_A;c_Clostridia;o_Oscillospirales;f_CAG-272;g_Flemingibacterium | 2.30E-06   | 9.08E-06   | ...  |

#### 1.2 Metabolite abundance table

- Rows represent metabolite IDs, and columns represent sample IDs in the same order as in the microbial abundance table.

| Metabolite                              | PRISM.7122 | PRISM.7147 | ...  |
| --------------------------------------- | ---------- | ---------- | ---- |
| C18-neg_Cluster_0001: NA                | 0.0        | 1635.54    | ...  |
| HILIC-pos_Cluster_0245: 1-methylguanine | ...        | ...        | ...  |

#### 1.3 Metadata table

- Rows represent samples. The `Study.Group` column identifies disease samples (`UC` or `CD`) and healthy controls (`Control`).

| Sample                 | Study.Group | Age  | Fecal.Calprotectin | ...  |
| ---------------------- | ----------- | ---- | ------------------ | ---- |
| PRISM.7122             | CD          | 38   | 207                | ...  |
| Validation.LLDeep_0001 | Control     | 40   | 10                 | ...  |

## 2. Construct phylogeny features

Phylogeny feature construction follows three processing stages:

```
phylo_fea.py` → `mic_clr_process.py` → `phylo_group.py
```

The workflow is as follows:

- `phylo_fea.py`**:** Aggregates microbial abundance features belonging to the same genus and maps genus names to NCBI taxonomy IDs (genera without matching taxonomy IDs are excluded). It then constructs a genus-level phylogenetic tree based on NCBI taxonomy and reorders microbial taxa through postorder traversal to obtain a reordered abundance profile.
- `mic_clr_process.py`**:** Applies centered log-ratio (CLR) transformation to the reordered microbial abundance profile generated by `phylo_fea.py`. 
- `phylo_group.py`**:** Generates an abundance profile representing distantly related taxa through interval-based sampling of the CLR-transformed, reordered microbial abundance profile.
- **Feature concatenation:** Concatenates the representations generated by `mic_clr_process.py` and `phylo_group.py` to construct the phylogeny features used as input to the model.

The precomputed feature tables `data/IBD/DL_data/microbiome_Train_phylo.csv` (6,558 × 155) and `microbiome_Test_phylo.csv` (6,558 × 65) are included in the repository. Therefore, **this step is optional**: `main.py` regenerates a table only if it is missing. The NCBI taxonomy database requires an internet connection for its initial download and may change over time. The provided tables preserve the feature set used in the manuscript.

### 3. Run PCMDM2

To train PCMDM2, perform five-fold cross-validation, and generate predictions for the external cohort, run:

```bash
python main.py
```

The `main.py` script:

- Performs five-fold cross-validation (`KFold(n_splits=5, shuffle=True, random_state=123)`) on  train data. 
- Trains a final model using all train data and predicts metabolite abundances for test data.

### 4. Evaluate downstream host phenotype classification

```bash
python Classification_Evaluation.py
```

The script evaluates three representations of the external cohort: measured microbial abundance profiles, measured metabolomic profiles , and PCMDM2-predicted metabolomic profiles . Each representation is evaluated using LASSO logistic regression with five-fold cross-validation. Run Step 3 before this analysis.
